# Data and model inputs

The repository includes selected group-level analysis tables, but no source datasets, model weights, hidden states or participant-level results. Obtain the external inputs from their publishers.

| Input | Role | Source and version |
| --- | --- | --- |
| Self-Regulation Ontology (SRO) Complete and Retest datasets | Behavioural task sessions and participant split | [Source repository](https://github.com/IanEisenberg/Self_Regulation_Ontology), commit `4e6e837fb5aaca87ed5914fd9be251156f43eec9` |
| Psych-101 | Task materials and model-task context | [Dataset](https://huggingface.co/datasets/marcelbinz/Psych-101), revision `611565c66395e2787cd7e3305149bb75dc138024` |
| Llama 3.1 8B | Matched 8B base model | [Publisher model page](https://huggingface.co/meta-llama/Llama-3.1-8B); revision recorded in `configs/stage0.yaml` |
| Minitaur 8B | Cognitively trained 8B model | [Publisher model page](https://huggingface.co/marcelbinz/Llama-3.1-Minitaur-8B); revision recorded in `configs/stage0.yaml` |
| Llama 3.1 70B and Centaur 70B adapter | Matched NF4 base and adapted models | [Base model](https://huggingface.co/meta-llama/Llama-3.1-70B) and [adapter](https://huggingface.co/marcelbinz/Llama-3.1-Centaur-70B-adapter); file identity and revision details below |

`scripts/01_fetch_public_sources.py` acquires and verifies the pinned SRO input and two 8B models. Some model repositories require acceptance of publisher terms before access. Downloading these files does not grant permission to redistribute them.

`configs/original/splits.json` is generated by `scripts/original/02_build_sro_sessions.py` from the pinned SRO input and frozen seed. It is ignored by Git because it contains participant-level pseudonyms. The 70B extension expects verified, separately stored layer-60 state arrays and their metadata; they are not part of this repository.

The Centaur adapter revision used for the 70B analysis was `159600db8be99dc183c289923148dfd96cbd8e07`. The base model came from ModelScope as `LLM-Research/Meta-Llama-3.1-70B`. Its requested revision was `master`, which is not immutable. The downloaded files were verified against local SHA-256 records. [`nf4_model_identity.json`](../manifests/public/nf4_model_identity.json) records the adapter revision, adapter weight checksum and base-model inventory identity; [`llama70b_modelscope_source.json`](../manifests/public/llama70b_modelscope_source.json) lists the expected base-model files.

The Llama 3.1 base model and Centaur adapter are subject to the [Llama 3.1 Community License](https://huggingface.co/meta-llama/Llama-3.1-70B). The repository's CC BY 4.0 license does not apply to them.

[`source_data/`](../source_data/README.md) contains checked group-level analysis tables for the shared readout, controls, retained information, Jacobian access and intervention statistics. These are analysis outputs, not yet a complete panel-by-panel source-data package for the manuscript figures. The corresponding plotting scripts are still being prepared. See [`results-map.md`](results-map.md) for the current code-to-figure mapping.
